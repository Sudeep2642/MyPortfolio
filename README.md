## 🗺️ THE WORLD MAP  <sub>(this repo)</sub>

</div>

This is the source for my personal site — rendered not with a template, but with a **hand-built 3D WebGL boss arena** for a hero. No engine plugins carrying the weight: the loading sequence, cursor, reveals, and the pathfinding visualization are all built from raw React + Three.js, no animation library equipped.

**🔗 Enter the world → [sudeep-bhimannavar.vercel.app](https://sudeep-bhimannavar.vercel.app/)**

## ⚙️ HOW TO INSTALL  <sub>(run locally)</sub>

</div>

```bash
# clone this world
git clone https://github.com/Sudeep2642/<repo-name>.git
cd <repo-name>

# equip dependencies
npm install

# boot the game
npm run dev
```

Runs at `http://localhost:5173` — Vite's default port.

```bash
npm run build     # compile for production
npm run preview   # preview the production build
```
